# 回归清单（Regression Checklist）

发版前或较大改动后，在至少一台真机上按本清单过一遍。改动涉及设备差异（输入法、系统权限、厂商定制）时，每台目标设备都要过。每批 commit 前的装机验证也以此为准，呼应 AGENTS.md「每次改动必须装机验证」。

## 0. 准备
- [ ] 确认待测包的 versionName / versionCode
- [ ] 如需卸载重装，先确认设备上数据可丢（插件、会话、模型配置）
- [ ] 记录设备：型号、系统版本、序列号

## 1. 模型接入
- [ ] Base URL / API Key / 模型名填写并保存
- [ ] 保存后核对持久化值正确（`run-as` 读 shared_prefs；密文应为 12 IV + 16 tag + 密钥长度）
- [ ] 输入框显示截断不代表存储截断，以持久化值为准
- [ ] 上下文上限留空走默认

## 2. 聊天主链路
- [ ] 发消息收到流式回复，无卡顿
- [ ] 思考过程可折叠 / 展开
- [ ] Markdown、代码块、表格渲染正常
- [ ] 会话历史：新建、切换、删除（删除有确认弹窗，删后列表刷新）

## 3. 工具门禁
- [ ] 触发 read_clipboard：弹窗含工具中文名、来源、敏感内容提示
- [ ] 拒绝：工具失败，模型如实告知无法读取；再次请求弹窗复现（拒绝不记忆）
- [ ] 允许一次：工具成功执行，结果正确
- [ ] 重启前不再询问：本进程内不再弹窗
- [ ] 弹窗「加入白名单」：工具直接放行，名单持久化
- [ ] 弹窗「加入黑名单」：工具被拒，名单持久化
- [ ] 禁止名单优先于档位：切到放行档后触发已拉黑工具仍被拦截，审计记「工具在禁止名单中」
- [ ] 严格档：只读工具也被拦截（如 memory_search）
- [ ] 放行档：不弹窗直接执行
- [ ] 档位切换后立即生效，无需重启

## 4. 插件（Dex APK 通道）
- [ ] 自测页正常
- [ ] 入口默认隐藏：插件页无「导入 APK」按钮与说明文字；未解锁且无插件时「动态插件」整区不显示
- [ ] 连点插件页标题「插件」15 次（3 秒内）解锁，「导入 APK」出现且不再消失
- [ ] 导入 APK：信任弹窗展示来源与哈希
- [ ] 允许后插件工具可调用，且照样过门禁
- [ ] 契约版本：无版本声明的旧插件正常加载；声明大版本不兼容（如 2.0）的插件被拒，日志报「契约版本不兼容」
- [ ] 卸载插件后信任记录同步清除；重导入同一 APK 静默通过
- [ ] debug 构建同签名插件免弹窗（仅 debug 包验证）

## 5. 插件（WASM 通道）
- [ ] 「导入 WASM」按钮在 WASM 插件区，样式与既有卡片一致
- [ ] 导入 `examples/wasm` 构建的 `.wasm`：弹窗展示工具名（`wasm_<id>_<工具名>`）、描述、能力声明与文件哈希
- [ ] 确认后插件出现在列表，工具可被模型调用且执行结果正确
- [ ] 喂无效文件：弹解码错误而非崩溃
- [ ] 页面「移除」：插件消失、信任登记吊销；重装同一文件重新弹窗
- [ ] release 包（R8 混淆）下 WASM 全链路可用（发版前必测）

## 6. 其他
- [ ] 启动时更新检查不阻塞、不误报
- [ ] 人设卡导入（JSON / PNG）
- [ ] MCP 配置读写（改动涉及 MCP 时）
- [ ] 前台服务与通知（改动涉及后台任务时）

## 7. 清理（测完必做）
- [ ] 测试会话删除
- [ ] Download 中的测试 APK / WASM 文件删除
- [ ] 测试插件移除（含 WASM）
- [ ] 门禁档位与名单恢复原状
- [ ] 如验证过入口解锁，解锁标记还原（`run-as` 清对应 shared_prefs 键）

## 附：已知设备差异
| 设备 | 注意点 |
|---|---|
| 安卓 12（OPPO）| 搜狗输入法吞横杠；`input text` 只支持英文 + `%s` 代空格 |
| 安卓 14（Redmi）| 讯飞输入法，`input text` 正常 |
| 安卓 16（OPPO）| 搜狗变体需切英文模式，行首偶吞字符；键盘开着会遮挡底部按钮 |
